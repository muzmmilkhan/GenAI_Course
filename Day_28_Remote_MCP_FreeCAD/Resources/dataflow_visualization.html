FreeCAD Remote MCP Architecture & Internal Data Flow

Clear visual guide: How FastMCP embeds into FastAPI (ASGI), how JSON-RPC 2.0 travels over HTTP/SSE, and how the WebSocket relays commands to FreeCAD.

1

Why Uvicorn & FastAPI for an MCP Server?

In remote_mcp_server.py, you run uvicorn.run(app). Why?

Under the hood, FastMCP produces a Starlette ASGI application when calling mcp.http_app(transport="sse"). Because FastAPI is also built directly on Starlette/ASGI, it mounts FastMCP natively!

// 1. FastMCP gives a Starlette ASGI sub-app
mcp_app = mcp.http_app(transport="sse", path="/sse")
// 2. FastAPI mounts it under /mcp
app = FastAPI(lifespan=mcp_app.lifespan)
app.mount("/mcp", mcp_app)
// 3. FastAPI also handles the FreeCAD WebSocket tunnel
app.add_api_websocket_route("/ws/agent", ...)

✅ Compatibility Key: Both FastMCP and FastAPI share the same Python ASGI interface, allowing a single Uvicorn server to host both the MCP HTTP endpoints and your FreeCAD WebSocket agent!

2

How Does HTTP Carry JSON-RPC 2.0?

MCP requires JSON-RPC 2.0 messages. But your diagram shows HTTP POST and SSE stream. How does the conversion happen?

HTTP does not replace JSON-RPC. HTTP is merely the transport envelope (the delivery vehicle) carrying the JSON-RPC string inside its body.

1. Client Request: POST /mcp/messages $\rightarrow$ JSON-RPC 2.0 is in the HTTP Request Body.
2. Server Stream: GET /mcp/sse $\rightarrow$ JSON-RPC 2.0 response streamed back as an SSE Event.
3. Bridge Proxy: npx mcp-remote forwards Claude Desktop's local stdio to those HTTP endpoints.

💡 No conversion loss: Claude Desktop writes JSON-RPC $\rightarrow$ mcp-remote POSTs it over HTTP $\rightarrow$ FastMCP deserializes the exact same JSON-RPC!

End-to-End System Architecture Breakdown

Understanding the 3 distinct execution environments and how they communicate.

Environment 1 User Laptop

Claude Desktop + mcp-remote

Claude Desktop only supports local child processes via stdio. To talk to the cloud, Claude config spawns npx -y mcp-remote <url>.

Standard I/O: Stdin / Stdout (JSON-RPC)
Network: HTTPS POST & SSE Client
Environment 2 Cloud Host (Render)

FastAPI + FastMCP (remote_mcp_server.py)

Managed by uvicorn. Hosts the Starlette FastMCP app on /mcp and maintains the WebSocket hub on /ws/agent.

FastMCP Tools: @mcp.tool() decorators
Future Registry: Maps UUIDs to active requests
Environment 3 FreeCAD App Process

PySide QWebSocket Agent (freecad_server.py)

Runs as a macro inside FreeCAD. Opens an outbound tunnel to Render. Pops CAD scripts and runs exec(code) safely in FreeCAD's Qt GUI main thread.

Execution: safe_execute(code)
Context: App, Gui, Part, ActiveDoc
