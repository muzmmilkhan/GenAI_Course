# Day 10 - Build an AI Agent From Scratch (ReAct)

**What you will learn:** What an agent really is - a loop of Thought -> Action -> Observation - written in plain Python with no framework.

## Before you start
- Do the one-time setup in the [course README](../README.md) (`uv sync` + `.env`).
- Open a terminal **inside this folder**:
  ```bash
  cd Day_10_Agents_From_Scratch_ReAct
  ```
- Keys: `GOOGLE_API_KEY` (Gemini). `GITHUB_TOKEN` optional.

## Lessons (do them in this order)
| # | Lesson | How to run |
|---|--------|------------|
| 1 | Read README.md (how the loop works) | - |
| 2 | Look at the tools | open tools.py |
| 3 | Run the agent | `uv run python main.py` |

> `.ipynb` files are Jupyter notebooks. Open them in VS Code (choose the `.venv` kernel from the course root) or run `uv run jupyter lab` from the course root.
